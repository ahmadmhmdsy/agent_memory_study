- `check_long.py T03 … T16`: all 14 have 7 tests (5 fact); the reference passes everything except
  `test_stale_*` ("wrong with ref: none"), and no fact test passes on the start repo.
- `check_facts.py T03 … T16`: 12 projects clean, 2 flags, both reviewed and fine:

    (through a `for m in ("ann", "bob", "cy", "dee")` loop, which the checker does not trace as call
    inputs), then read back from `booked`/`waitlist`. The tested behaviour (full class → end of waitlist,
    `book` returns False; a place returns True) is stated verbatim in the session 1 `DEC`.
  - **T16 overdue_order** — flags `'ivy'`, `'aloe'`, `'moss'`, `'rose'`. Plant names added in a
    `for p, every in (...)` loop, so again inputs echoed back. The order tested (most days past the next
    day first, then by name) is the session 2 `later()` step; by name alone the result would differ
    (`aloe, ivy, moss, rose`), so the test does check the stated step.
