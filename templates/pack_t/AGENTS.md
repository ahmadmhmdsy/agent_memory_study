# AGENTS.md

Read this file first in every session. It is the entry point to the project's memory.

## Files

- `docs/decisions.md`: rules and design decisions that the code must follow. One line each, with the session that made it.
- `docs/handoff.md`: what the last session did and what the next session must do first.

## At the start of a session

1. Read `docs/handoff.md` and `docs/decisions.md`.
2. Follow every rule and decision in `docs/decisions.md`, even when the request does not repeat it.

## Before you finish a session

1. `docs/decisions.md`: add every new rule or decision you were given or made. Never delete one; mark it superseded instead.
2. `docs/handoff.md`: rewrite it for the next session: what you did, what is unfinished, what to do first.
